# 🦆 WildGooseChase: Japan Real Estate Candidates

Live interactive dashboard tracking affordable houses in Japan under **10,000,000 JPY** meeting strict safety and livability criteria:
- **Elevation $\ge$ 40m** (Laser DEM verified via GSI Japan)
- **Landslide Safe** (GSI Disaportal hazard-free)
- **Within 3h of Central Tokyo**
- **Ocean, Lake, or Scenic Mountain Views**
- **Normal Road Access (No Cliff Edges / 60-stair climbs)**

---

### 🌐 Live Interactive Dashboard
👉 **[Open Live Dashboard](https://horohoro.github.io/wildgoosechase/)**

Features:
- Filter by Price, Elevation ($\ge 40\text{m}$, $\ge 100\text{m}$, $\ge 600\text{m}$ Summer Coolness), View Type, Monthly HOA/Onsen Fees, and Terrain.
- Interactive Map powered by GSI Japan (国土地理院) with topographic contours & aerial satellite imagery.
- In-card photo flipping & full-screen lightbox with arrow-key keyboard navigation (`←` / `→`).
- Direct links to SUUMO listings and GSI Hazard Map Portal.
